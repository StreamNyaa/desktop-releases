The Windows desktop beta: anime browsing, release schedules, your watch list, and a built-in player.

**[Download the Windows installer](https://github.com/StreamNyaa/desktop-releases/releases/download/v0.1.15-beta.1/StreamNyaa_0.1.15_x64-setup.exe)** · [Installation guide](https://github.com/StreamNyaa/desktop-releases/blob/main/docs/install.md)

This version improves series timelines and season labels. It includes batch episode-file selection, source matching, local history, Sub-timed recent releases, and episode-completion controls.

**Requirements:** Windows 10/11 x64, an x86-64-v3 compatible processor, and Microsoft Edge WebView2 Runtime. The player is included.

The installer is **unsigned**. Check its SHA-256 against `SHA256SUMS.txt` and keep security software enabled. If you are upgrading, export a personal backup from Settings and quit the app first. The app version is 0.1.15; Beta is the release label.

Torrent playback downloads data, can upload pieces, and exposes your IP address to peers and trackers. StreamNyaa does not host video. Use only content you have the right to access and share.
