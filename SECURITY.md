# Security

## Report privately

Use **[Report a vulnerability](https://github.com/StreamNyaa/desktop-releases/security/advisories/new)** for a security problem. Include the affected version, impact, and the smallest safe reproduction. Do not put tokens, private logs, or exploit details in public Issues.

Testing permission here covers your own installed app, your own account, and controlled local fixtures. It is not permission to access another user's data, scan unrelated providers, interfere with peers, or load-test the production site. Acknowledgement and fixes depend on available maintainer time; there is no bug-bounty or response-time promise.

## Current support

This repository publishes the current desktop beta. Include its version in your report. Download updates from this repository.

The installer is unsigned. Verify its release hash, keep security software enabled, and use only content you have a right to access and share. If antivirus flags it, stop and send the detection name, version, and SHA-256 privately. We will not ask you to disable protection so a test can pass.

## Do not share

Never upload credentials, login/session information, private configuration files, personal backups, private tracker passkeys, or an entire app-data/log directory.
