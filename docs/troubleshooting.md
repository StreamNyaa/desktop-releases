# Troubleshooting

## Release and installation

- The installer is unsigned. A SHA-256 match and an antivirus scan are useful checks, but do not replace publisher verification or a security audit.
- This is the Windows x64 build only. Playback requires an x86-64-v3 compatible processor; older CPUs may not run its player.
- Beta updates are posted in this repository. Download the new installer and follow the upgrade guide.

## Sources and playback

- Provider outages, throttling, outdated listings, slow peers, mislabeled uploads, and unsupported files can still prevent playback. A seeder count is a listing's report, not proof that your PC will receive playable data.
- Strict/Balanced matching is designed to exclude known installment conflicts and uncertain matches. Broad mode can expose uncertain listings for manual review. Never treat a high rank as a verified identity or safety certificate.
- Batch packs need the correct file. Missing episodes, duplicate encodes, extras, unknown numbering, and combined-episode videos may need manual choice or be unusable. Do not assume that a pack claiming “1–10” contains ten verified episodes.
- Codec, subtitle, and GPU/driver differences can affect playback. Include those details when reporting a player problem.
- Release timing on Home is separate from source availability. A confirmed Sub time, or the labeled estimated window, does not guarantee that a playable source exists.

## Account data and schedules

- Keep a personal backup. Cloud resumes cover recent anime; they are not a full backup of an older local archive.
- Provider metadata can be incomplete, stale, or contradictory. Report the exact title and provider ID when a timeline, episode, or schedule is wrong.
- If a feature is temporarily unavailable, keep the error message and time, then retry later. Include those details when reporting a recurring problem.

For a problem you can reproduce, send the steps and a small sanitized diagnostic excerpt. See [Reporting feedback](feedback.md).
